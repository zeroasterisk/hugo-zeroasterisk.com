# A2UI v0.9: The New Standard for Portable, Framework-Agnostic Generative UI

**Originally published on [Google Developers Blog](https://developers.googleblog.com/a2ui-v0-9-generative-ui/)** - *April 17, 2026*, by the Google A2UI Team.

A2UI v0.9 introduces a new Agent SDK, a shared web-core library, and cross-platform renderers, allowing AI agents to drive existing design systems on any device with low-latency streaming — all under a framework-agnostic standard for Generative UI.

## Why This Matters

Generative UI needs to be portable across platforms without locking developers into one framework's rendering model. This release is foundational to the A2UI Storybook integration work I've been involved in.
