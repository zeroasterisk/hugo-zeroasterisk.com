# Delight Users by Combining ADK Agents with Fancy Frontends Using AG-UI

**Originally published on [Google Developers Blog](https://developers.googleblog.com/en/delight-users-by-combining-adk-agents-with-fancy-frontends-using-ag-ui/)** - *December 11, 2025*.

The ADK and AG-UI integration lets developers pair a powerful ADK-based agent backend with a flexible, interactive frontend — combining Google's Agent Development Kit with the AG-UI protocol to build richer, more responsive AI applications.

## Why This Matters

Backend agent logic and frontend UX are often built by separate teams with separate toolchains. AG-UI plus ADK gives a clean seam between the two, similar in spirit to the A2UI + MCP Apps architectural patterns.
